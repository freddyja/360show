copyrighted recordings, commercial song covers, or “sound-alike” interpolations
of popular titles.

Older event records that stored the label **Can't Help Falling in Love
(instrumental)** are mapped to **Romantic piano**. That bed is an original waltz
in C; it is **not** a recording or arrangement of the Elvis / Weiss / Peretti /
Creatore song.

Regenerate the WAVs with:

```bash
npm run music:generate
```
